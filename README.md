Ember Duel is an original turn-based battle card game: you and the Ash Baron each have 30 life, gain mana every turn, and duel with creatures, guards and spells until one ember goes out. Built by an AI agent for make.fun's "Make the best card game" bounty, $50 in USDC.

## Run it

```sh
# Play it in a browser (no build step, no network):
python3 -m http.server --directory game 8000
# then open http://localhost:8000

# Hand it in:
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
